# Learning buddy reference library

44 owner-approved generated reference items in six sheets: 12 expressions, 12 study/support poses, 8 outfits, and 12 accessories/materials. Built with GPT image generation from the owner original source crops; accessory sheet was generated without character reference inputs. This is a reusable character/style conditioning library, not a prebuilt lesson illustration library.

Extract the ZIP and open `index.html` to review individual named PNGs. `catalog.csv` lists labels and caveats. `manifest.json` records sheet/crop coordinates, hashes, original authority, intended framing, prompts, and approval flags. Images have opaque white backgrounds. Source original crops/pages are included under `original-authority`; their earlier provenance includes paths in the earlier source pack for audit, not paths automatically loadable in this archive.

## What the expressions mean

Neutral friendly, open smile, surprise, concentration, thinking, persistence; puzzled, curious, mild frustration, relief, pride, tiredness. These are artistic directions, not diagnoses or verified recognition labels. Concentration/persistence are visually similar. The relief image reads more like delight. Keep mild frustration as normal effort, never shame or punishment. Tiredness signals permission to take a break.

## Pose limitations

Building-with-tiles and considering-choices are upper-body at a work surface, not full-body references. Finger-tracking is broadly pointing toward a blank page; it is not proof of the correct tracking procedure. Asking-for-help may also read as greeting. Actual generated worksheet scenes still need task-specific prompts and all scene checks. Do not equate a useful pose reference with a validated learning activity.

## Review and use

1. Howard approved this library on 2026-10-09 against his original character references. All 44 generated items have `owner_approved=true`; `live_identity_gate_passed=false` remains unchanged. This is approval for reference use, not proof of generation reliability or permission to replace the original identity authority.
2. Start each generation with the original identity reference. Add only the relevant approved expression or pose and, if necessary, the approved theme outfit. Begin with 2-3 images; do not send the entire atlas. State reference roles explicitly. More references can conflict and increase latency.
3. Judge every candidate against the immutable original, never only a generated pose/outfit or anchor. Maintain identity >=0.85; expression changes are allowed without changing identity. Owner approval is separate from measured model gate calibration.
4. Clothing refs may reduce costume transformation work, but this hypothesis has not been tested. A diver's clear dome is fictional cartoon equipment. Hats, glasses and ear defenders may obscure hair/eyes and need explicit owner acceptance of the resulting look.
5. Common materials remain blank. Keep actual worksheet text and answers vector-rendered; accessories must never leak a completed practice answer.
6. Confirm multi-reference transport, thread-shared limits and accounting before Muse makes paid OpenRouter calls. These assets are not live OpenRouter tests and no first-pass/latency claim follows from this library.

Individual crops are pixel-exact regions of the generated sheets after removing white margins, not separately generated images. Original files remain untouched. The full prompt for every sheet is in `prompts/`. No worksheet pipeline defaults or canonical reference have been changed.

The learning-moods source sheet is stored as lossless WebP to reduce GitHub upload size. Its decoded RGBA pixels were verified identical to the generated PNG. The original PNG SHA-256 remains recorded in the manifest; all 44 individual reference PNGs retain their original bytes and hashes.
